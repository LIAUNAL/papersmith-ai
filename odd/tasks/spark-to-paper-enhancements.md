# Spark-To-Paper Benchmark & Paper Smith Enhancement Plan (0.69.0)

Objective: Incorporate key zero-cost capabilities inspired by Spark-To-Paper-Skills (arXiv:2608.11924) alongside Command Center UI fixes (multi-agent terminal launcher and problem tree methodology) under a strict zero-additional-cost constraint (no paid APIs, no subscriptions).
Branch: feat/spark-to-paper-enhancements. Delivery: reviewable slices (~400 authored lines each).

## Specs

- S1 (SVG & Diagram Audit, net-new pipeline): Add a 100%-stdlib SVG audit that checks typography hierarchy, bounding-box collisions, and color contrast, sitting alongside the existing TeX+PDF auditor `skills/_core/figure/diagram_audit.py` (checks `overfull`, `size_switches`, `text_overlap`, `font_range`, `margins`, verdict pass/fail/unmeasured). The SVG pipeline is net-new input handling, not an extension of `skills/figure-review/` (which is raster PNG/PDF review only and "never compiles, never repairs"). No external VLMs, no paid image APIs. Contrast and SVG metrics have no in-repo counterpart to reuse; "Adobe core-14 metrics" is an inspiration, not an available library.
- S2 (Zero-Cost Citation Verification, split by trust domain): (a) CLI-side: add Semantic Scholar as a free resolver source for `paper_cli.py resolve` (stdlib `urllib`, no API key, graceful degradation consistent with the existing OpenAlex/Crossref/arXiv handling in `openspec/specs/literature-search/spec.md:57-61`). (b) Agent-side: document Allen AI ASTA (MCP) as an optional agent-side citation-grounding check; `.mcp.json` is agent-side only and never read by the CLI, so ASTA is not CLI-gated.
- S3 (Adversarial Citation & Hallucination Review): Define and implement the Anti-Skim protocol in `redactor.md` — every cited claim must quote-verify against a retrieved source before entering the manuscript; unverified citations are flagged, never silently kept. Add adversarial citation/hallucination checks to `paper-reviewer.md`. Each prompt edit lands in all four harness projections (`.pi/agents/`, `.claude/agents/`, `.opencode/agents/`, `.agents/agents/`) and is pinned by the parity suites (`test_paper_language.py`, `test_harness_parity.py`).
- S4 (Modular Venue Catalog as data): Add a machine-readable venue catalog (JSON data: venue slug, TeX Live document-class name, official guidelines URL, page/format limits) covering NeurIPS, ICML, IEEE conferences, IEEE Transactions, Elsevier, Springer, Frontiers, MDPI. No `.cls` files are vendored or shipped: the forge ships no document class (`odd/tasks/journal-finder.md:50`); acquisition stays per-workspace via `paper_venue.py acquire` (`skills/paper-writing/scripts/paper_venue.py`). Overleaf cloud synchronization is explicitly excluded.
- S5 (Cross-Platform Terminal Launch): Extend `detect_tools` and `launch_external` in `skills/_core/command_center/terminal.py` with Linux launch backends (GNOME Terminal, `x-terminal-emulator`, Konsole, Ghostty/WezTerm on Linux PATH) while leaving the macOS `open -na` path unchanged. Agent selection (herdr, claude, opencode, pi, antigravity, shell) already ships (`terminal.py:245-256`, `cli-console.js:126-149`, `phase-console.js:213-277`) and is a verification item, not new work.
- S6 (Command Center UI activation prompt & Problem Tree ordering): When `smith ui` opens with inactive CLI status (`authorized:false`, `agents: []`, pinned by `tests/test_command_center_terminal.py:194-199`), the UI surfaces a visible, dismissible prompt explaining how to activate (open the login URL). No server-side auto-activation: the cookie/HttpOnly login invariant is preserved. Invert problem tree rendering in `model-panel.js` strictly top-to-bottom: Direct Causes -> Central Problem -> Effects (currently effects → central → causes at `model-panel.js:89-91`), handling the `caused_by` cross-references ("from {ids}", i18n `conceptTree.causedBy`) so no reference precedes its referent in the new order.

# Caztor embed: review fixes, speed and the PDF tab layout (PR #196)

Objective: apply the dual review's fixes to PR #196 (Caztor in the PDF tab), keep the dashboard's CLI terminal working beside it, cut response time and resource use, and lay out the PDF tab's windows and panels better without losing any function. Branch `feat/caztor-hardening` from the PR head 4b2c2c93 (the contributor's `pr/caztor-embed`; maintainers can push to it). Delivery `ask-on-risk`. Runners: `.micromamba/envs/papersmith/bin/python -m pytest` (absolute `PYTHONPATH=$PWD/src:$PWD`, and once without the repo root as CI runs), `PATH=/usr/bin:$PATH npm test`, Caztor's `npx vitest run` and `npx tsc -b` under `caztor/`.

## Specs

- S1. User request (2026-11-24), verbatim: "vamos a aplicar esos cambios y optimizar 196, revisa que no rompa el mireor con el cli, explora opciones para optimizar los tienpos de respuesta y uso de recursos y revisa la disposicion de las ventanas y panales en el vidualizador de pdf en smith ui. usa playwritht y optimiza su disposicion sin perder funcionalidades".
- S2. "esos cambios": the four findings both reviewers confirmed on #196 (L2):
  1. Caztor's launch token is readable by any local process (served in index.html to any loopback request with an allowed Host); the dashboard's frame must be the only holder (a per-launch secret the dashboard passes only to its own frame), or the exposure documented.
  2. The sidecar holds its lock while Node.js and Tectonic download (300 s timeouts), so stop, the editor switch and shutdown block.
  3. Licensing before publishing: the vendor logos `NOTICE.md` flags for a brand-guideline review, third-party notices for the npm dependencies bundled into the server and web app, and a licence statement for `caztor/` itself.
  4. `pip install .` from a checkout runs `npm ci` and silently skips Caztor on failure, with no Node 26 check.
- S3. "que no rompa el mirror con el CLI" (assumption, stated to the user): the dashboard's agent terminal (the Smith CLI assistant window whose herdr workspace mirrors the agent pane, and every `sendToCli` button, including #196's "Run round N of the judge") keeps working with Caztor open in the PDF tab: focus and keyboard input, window stacking and resizing, commands typed into the open session.
- S4. Explore options to cut response time and resource use (Caztor's start, its polling and frame watch, the sidecar's process and memory, the dashboard's own requests in the PDF tab), measure them, and apply the ones that keep every function.
- S5. With Playwright, review how the PDF tab lays out its windows and panels (PDF viewer, Caztor editor, final-judge panel, style and redundancy panel, journal and venue, translation, the CLI terminal) and improve it without losing any function.

# Journal finder: free fallbacks when OpenAlex is unavailable

Objective: `/journal-finder` (and the PDF Preview panel) keeps working when OpenAlex cannot answer (no key, keyless demo budget spent, 429, network), by falling back to free scholarly APIs, and states plainly which sources answered and what is missing.
Branch: `feat/journal-finder-fallback` (from `main` 4805f183, v0.47.0). Delivery: release 0.48.0, update local `smith` and QMLEEG (pending the operator's go-ahead). Tests: `.micromamba/envs/papersmith/bin/python -m pytest -q -n 6`; `npm test`.

## Specs

- S0. The operator's request, verbatim: L1.
- S1. **Provider chain** in `skills/journal-finder/scripts/journal_cli.py`: `--source auto|openalex|crossref` (default `auto`). `auto` tries OpenAlex first; when it is unavailable (no response, 429 budget/quota, 401/403 key required, network error) the search continues with the fallback chain instead of refusing, and the result says so. `openalex` keeps today's behaviour (refuse when unavailable). `crossref` skips OpenAlex.
- S2. **Fallback similar works**: Crossref `/works?query=<phrases>&filter=type:journal-article,from-pub-date:<6 years ago>&rows=100&select=DOI,title,container-title,ISSN,published,subject` (polite pool: `mailto` from `PAPERSMITH_CONTACT_EMAIL`, at most 3 list requests/s, `PAPERSMITH_CROSSREF_URL` override), one query per facet like the OpenAlex path; plus Europe PMC (`/search?query=...&resultType=core&format=json`, `PAPERSMITH_EUROPEPMC_URL`) when the paper's application facet or keywords look biomedical (or always, merged; document the rule); plus Semantic Scholar `/graph/v1/paper/search` (`publicationVenue` with ISSN) only when `SEMANTIC_SCHOLAR_API_KEY` is set (header `x-api-key`). Aggregate per journal by normalized ISSN (fallback: normalized container title), keep journal articles only, keep up to 3 example works.
- S3. **Fallback cited venues**: DOIs from `paper/refs.bib` resolved through Crossref `/works/<doi>` (container-title, ISSN); journal-name entries matched against the aggregated journals by normalized title.
- S4. **Fallback journal metadata**: SJR CSV when imported (title, publisher, h-index, quartile, categories); DOAJ `/api/search/journals/issn:<issn>` (`PAPERSMITH_DOAJ_URL`) for OA, APC (`apc.has_apc`, `apc.max`), review process, subjects; Crossref `/journals/<issn>` for publisher when missing. Fit score: `similar_works` and `cited_in_paper` as today; `topic_overlap` uses SJR categories / DOAJ subjects vs the paper's keywords and facet phrases when OpenAlex topics are absent (or drops out and the weights rescale, as today); document which.
- S5. **Quartile without OpenAlex**: SJR when imported; otherwise `quartile: null`, `quartile_source: "unknown"`, a note naming `sjr-import` and `OPENALEX_API_KEY`; the quartile range filter keeps unknown-quartile journals only with `--include-unknown-quartile` (default: excluded, counted in `excluded_count` with a reason) — the panel shows the count and a toggle.
- S6. **Transparency**: the JSON gains `providers {similar_works: [...], cited_venues: [...], metadata: [...], quartile: "sjr"|"openalex-proxy"|"unknown"}` and `fallback {used: bool, reason}`; `api_calls.by_service` gains `europepmc`, `doaj`, `semanticscholar`; the response cache covers the new services. Each candidate carries `sources` (which providers contributed it).
- S7. **OpenAlex key guidance**: OpenAlex now requires a free API key for real use (keyless calls are a small demo allowance; a free key gives about $1/day of usage, 10x the keyless budget). The panel's budget line, the CLI notes on fallback, SKILL.md, README and docs say how to get it (openalex.org account -> openalex.org/settings/api) and to export `OPENALEX_API_KEY`; never request a key on the operator's behalf.
- S8. **Panel** (`static/journals-panel.js`, i18n es/en parity): a source selector (Auto / OpenAlex / Crossref), the providers line and the fallback banner with its reason, unknown-quartile count and toggle, per-row source badges; `POST /api/journals/search` accepts `source` and `include_unknown_quartile` and passes them through (validated).
- S9. **Tests** against fake servers for every provider: fallback triggered by 429/401/network, `--source` modes, Crossref aggregation by ISSN and by title, Europe PMC merge rule, Semantic Scholar only with a key (header asserted), DOAJ APC/OA mapping, unknown-quartile filtering and counting, providers/fallback fields, cache for new services, refusals unchanged in shape; panel render and endpoint pass-through tests. Docs: SKILL.md, README "Choosing and adapting to a journal", docs/skills.md section 19, docs/cli.md, docs/mcp.md env list; CHANGELOG 0.48.0.

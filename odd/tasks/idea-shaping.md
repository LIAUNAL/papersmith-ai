# Idea shaping: an optional guided phase before plausibility

Objective: an optional pre-plausibility phase where a guide agent asks key questions and helps a user with a vague idea refine topics and a base idea for `/plausibility`; launchable from the terminal (`smith idea`) and with its own `smith ui` panel. Branch `feat/idea-shaping` (from chore/release-0.83.0; merge main after 0.83.0 lands). Delivery: ask-on-risk. Runners: `.micromamba/envs/papersmith/bin/python -m pytest` with absolute `PYTHONPATH=$PWD/src:$PWD` and once with `PYTHONPATH=$PWD/src` only (as CI); `PATH=/usr/bin:$PATH npm test`.

## Specs

- S1. User request (2026-11-25), verbatim: "ahora, explora como podemos hacer mas amigable la construccion de palusability. cuando alguien tiene una idea vaga de su paper, las dos orqciones obligatorias de plausability pueden no ser suficientes. explora una fase previa, que se pueda lanzar si el usuario necesita guia para construir sus ideas, en donde a partir de preguntas clave, desde si tiene mcp de conocimiento como bancolia, o preguntanfo por si google scholar o experiencia onvestigativa, mas palabras clave o temas de interes, un agente guia ayude a depurar topics e idea base para la plausability. esta fase previa debe poder lanzarse desde cli por terminal y debe incluir panel propio en smith ui para facilitar la interaccion con el usuario"
- S2. Step 1, sources, is the user's decision, verbatim: "ajusra para que el uduario decida en 1 fuentes si conecta mcp bancolia u otro banco similar mcp o si no quiere incluir mcp tipo banco papers proyectos". Three choices: `banco-lia` (managed by smith; probed when chosen, the reason shown when unreachable, retry or change); another bank MCP (chosen from the workspace's `.mcp.json` servers smith does not manage, or added by command/URL; probed with `tools/list`: compatible when it exposes `search_bank` (optionally `taxonomy`) and then used like banco-lia in the panel and the CLI; otherwise usable only through the agent's own `mcp__<server>__*` tools, which the panel says); none (profile, interests, OpenAlex and Asta only; no bank is queried). Recorded in the brief; changeable later; every topic and the draft keep the source they came from.
- S3. Approved design (2026-11-25, user: "si, implementalo"): steps 2-6 after sources: (2) profile: ORCID, OpenAlex author, or a Google Scholar link used only to find the author in OpenAlex/ORCID (no Scholar scraping), the author's works summarised into topics; (3) experience: level, methods, data/equipment access, time; (4) interests: keywords, application domain, an admired paper; (5) three candidate topics with evidence (bank when chosen, recent OpenAlex volume, gap signals); the user picks or combines; (6) draft: problem and proposal in at least two sentences, checked live by the prompt gate; on approval it launches `/plausibility <draft>`.
- S4. Record `.papersmith/idea_brief.json` (answers, sources, topics, choice, draft and its gate result); plausibility and `/paper-type` may read it.
- S5. Terminal: `smith idea` runs the questions interactively; `--answers FILE.json` and `--bank banco-lia|none|<server>` run it without interaction; `smith idea show|draft|handoff` and the other verbs below.
- S6. Panel: an "Idea" tab in `smith ui`, shown for every line, a stepper for the six steps (source status chips, profile field, keyword chips, topic cards, draft editor with the gate score), a "Talk to the guide" button that types `/idea-shaping` into the agent and a "Launch plausibility" button. The Phase 2 card links to the tab. The existing Thematic help (keywords -> banco-lia -> draft, `banco_suggest.py`, `/api/plausibility/suggest`) is absorbed into the tab's flow.
- S7. Placement: lane "2a" (optional, before `/plausibility`); no new top-level stage: the eleven phases and their tests stay as they are. The flow template, docs and the Archify diagram name the new step.

## Contract between units (assumption made by the parent; units must keep it)

Engine package `skills/_core/idea/` (loaded by `smith idea` like `core/novelty.py` loads `skills/_core/results/novelty_gate.py`):
- `brief.py`: `PATH = ".papersmith/idea_brief.json"`; `load(root) -> dict` (empty brief when absent), `save(root, brief)` atomic; `record(root, step, data) -> dict` merges one step and appends a `history` event. Schema 1:
  `{"schema":1,"updated_at":iso,"bank":{"choice":"banco-lia"|"other"|"none","server":str|null,"compatible":bool|null,"tools":[str],"available":bool|null,"reason":str|null,"checked_at":iso},"profile":{"orcid":str|null,"openalex_author":str|null,"scholar_url":str|null,"display_name":str|null,"works_count":int|null,"topics":[{"name":str,"count":int}],"source":"openalex"|"none","reason":str|null},"experience":{"level":"student"|"early-career"|"experienced"|"senior"|null,"methods":[str],"resources":[str],"time":str|null},"interests":{"keywords":[str],"domain":str|null,"admired_paper":str|null},"topics":[{"id":"t1","title":str,"rationale":str,"keywords":[str],"evidence":[{"source":"bank:<server>"|"openalex"|"profile"|"operator"|"guide","detail":str,"count":int|null,"url":str|null}]}],"chosen":{"topic_ids":[str],"note":str|null},"draft":{"text":str,"source_topics":[str],"gate":{"ok":bool,"score":number|null,"missing":[str]},"approved":bool,"approved_at":iso|null},"history":[{"at":iso,"step":str}]}`
- `bank.py`: `choices(root) -> {"managed":"banco-lia","others":[{"server":str,"command"|"url":...}]}`; `probe(root, server) -> {"available":bool,"compatible":bool,"tools":[str],"reason":str|null}` (stdio JSON-RPC `initialize` + `tools/list`, reusing/generalising `banco_suggest`'s session); `choose(root, choice, server=None) -> bank dict` (records it); `search(root, query, limit) -> {"available":bool,"hits":[...],"reason":...}` only for a compatible chosen bank; `add_server(root, name, command=None, url=None)` writes the entry to `.mcp.json` (keeps other servers).
- `profile.py`: `lookup(orcid=None, openalex_author=None, scholar_url=None, name=None) -> profile dict` via OpenAlex (`/authors/orcid:...`, `/authors/A...`, `/authors?search=` with the name parsed from the Scholar link or given); works -> topics (OpenAlex concepts/topics counts); offline/unreachable -> `{"source":"none","reason":...}`, never raises.
- `topics.py`: `propose(root, n=3) -> list[topic]` deterministic: from interests, profile topics and (when the bank is compatible) bank hits; evidence counts from OpenAlex works of the last 4 years (`/works?search=&filter=from_publication_date:`) when reachable; each evidence item names its source. `choose(root, topic_ids, note=None)`.
- `draft.py`: `compose(root) -> draft` (two or more sentences naming a problem and a proposal from the chosen topics, experience and interests); `check(text) -> gate` using `skills/_core/command_center/prompt_gate.py` with the plausibility rules; `store(root, text)`; `approve(root)` refuses when the gate fails; `handoff(root) -> "/plausibility <text>"` refuses unless approved.
- `idea_cli.py` (argparse, JSON on stdout with `--json`): verbs `start` (interactive steps 1-6 with `input()`, or non-interactive with `--answers FILE.json`, `--bank`, `--yes`), `show`, `bank [--list|--probe SERVER|--choose banco-lia|none|SERVER|--add NAME --command ... | --url ...]`, `profile [--orcid|--openalex|--scholar|--name]`, `experience`, `interests`, `topics [--propose|--choose t1,t2]`, `draft [--compose|--text -|--check]`, `approve`, `handoff`. `smith idea [VERB] [ROOT]` forwards to it (`src/papersmith/core/idea.py`, registered in `src/papersmith/cli.py`; plain `smith idea` = `start`).
- Server (unit T3): `GET /api/idea` (brief + bank choices), `POST /api/idea/bank|profile|experience|interests|topics|choose|draft|approve` (same-origin checked like `/api/paper-type/*`), each returning the updated brief.

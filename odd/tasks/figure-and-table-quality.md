# Figure and table quality: diagrams, experiment plots, tables, manuscript visual QA

Objective: every diagram and experiment figure prints legibly and cleanly in the manuscript (no overflow, overlap, titles, backgrounds or wasted space; text at least 70% of the body size at printed scale), tables stay inside the text block at the same font floor, and the compiled manuscript gets a visual QA pass.
Branch: feat/figure-and-table-quality. Delivery: ask-on-risk (merge pending the user's word). Tests: `.micromamba/envs/papersmith/bin/pytest`.

## Specs

- S1: "explora el agente creador y revisor de figuras de morfeo, para los diagrmaas de concepto, experimentos, propuesta etc explora y aprovecha estos agentes o crea unos que construyan esos diagrmaas, eviten sobreflujo de textos, desborde, traslape, etc." — reuse MORFEO's pattern (spec-driven TikZ with explicit `\fontsize`, mechanical audit, single-pass visual reviewer on a ≤1400 px preview with PASS+uncertainty) in `experiment-diagrams` and the paper diagrams (`paper_tikz`, `diagram-author`): no relative font switches, overfull boxes = 0 from the kept log, vector text-overlap check, transparent background for paper export.
- S2: "para las figuras que salen de expeirmentos, asegurate de exportarlas en pdf para compilar en el maniscrito, con boedes tighlayout, evitando dejar fondos o desperdicio de espacio." — a shipped matplotlib style/helper for experiment repos: `savefig(pdf, bbox_inches="tight", pad_inches≈0.02, transparent=True)`, no facecolor; `place` refuses raster plots for line/scatter figures and checks PDF with embedded text, no full-page background rectangle, margin waste bounded.
- S3: "asegurte de que los textos de las figuras, incluidas de diagramas y de experimentos, no sean mas pequeñas al 70% del tamño del texto principal del manuscrito, incluido labels, ticks." — measured rule: every text span of a figure, at its printed scale (placed width / figure MediaBox width, or the declared inclusion width for standalone checks), ≥ 0.70 × body font size (body from the `\documentclass` option, default 10 pt). Replaces `legibility: unmeasured`.
- S4: "evita usar titulos en las mismas figuras del experimento, estos deben describirse en el caption de las mismas." — no in-figure titles for experiment plots (helper forbids `set_title`/`suptitle`; checker flags a top-band title span); the caption carries it.
- S5: "aplica la misma filosofia para las tablas del manuscrito respecto al tamaño, evita que las tablas se desborden de las margebes del manuscrito." — table rules in contracts 02/03 (+ Spanish copies): `tabularx`/`booktabs`, no `\resizebox`/`adjustbox` scaling below 0.85 and no font below 0.70 × body; table text inside `\textwidth`; lint in paper-writing.
- S6: "explora si puedes usar playwrigth l algo similar para verificar calidad visial del mansucrito, con sus figuras y tablas" — manuscript QA after compile: render pages (pdftoppm), measure with pypdfium2 (declared dependency; PyMuPDF is AGPL and undeclared) every span/image/drawing against the text block (overflow > 1 pt), per-figure printed font floor, table overflow; report `paper/.qa/qa.json` + page PNGs, shown in the dashboard; Playwright stays for the dashboard UI (existing `ui/e2e`).

# Manuscript translation to Spanish (after the English manuscript)
Objective: an optional, gated step that translates the finished English manuscript block by block into neutral academic Spanish for journals that only receive Spanish, with a Spanish style reviewer and deterministic redundancy, AI-mark and text-quality estimators. Branch: feat/journal-scope-publindex (released together with the national journal scope). Test runner: `.micromamba/envs/papersmith/bin/pytest`.

## Specs
- S1. "revisa y explora como pasar el manuscrito a español, si para revistas colombianas solo se acepta español."
- S2. "debe hacerse todo en ingles y luego traducirse a español" — the English manuscript stays the canonical source (`paper/main.tex`, blocks under `paper-writing` markers); the translation is a derived artifact under `paper/translations/es/` and never edits the English paper.
- S3. "teniendo cuidado de no generar marcas de IA, redundancia, y respetar las reglas y estrucutras que tenemos" — each Spanish block keeps the English block's citation keys, `\label`/`\ref`/`\eqref` targets, math, numbers and paragraph count (fidelity gate); no new claims, no dropped sentences; neutral academic Spanish (no regionalisms, no tuteo/voseo, no spaced em dash or `--` in prose, no English calques).
- S4. "mira el proyecto redaccion propuestas morfeo si podemos usar aglo de los skills o agentes para redactar en español" — reuse Morfeo (`LIAUNAL/propuestasmorfeo-ia`, Apache-2.0): `scripts/estilo_es.py` (style/flow/redundancy scorer, `verificar` fidelity), `.claude/skills/estilo-natural-es` (pattern catalog), `.claude/agents/revisor-redundancia.md` (read-only reviewer pattern), with attribution.
- S5. "explora e implementa la mejor alternativa para pasar a español si se requiere despues de tner el manuscrito en ingles"
- S6. "asegurate de incluir revisor de estilo y estimador de redundancia e ia y calidad de texto para cuando se pasa a español"
- S7. "antes de hacer push y release" — push and release wait for this feature.

### Contract shared by the CLI and the dashboard (assumption, fixed here)
- Layout: `paper/translations/es/blocks/<block-id>.tex` (Spanish body of each canonical block); `paper/translations/es/translation.json` (state); `paper/translations/es/main.tex` (built); `paper/translations/es/main.pdf` (compiled); `paper/translations/es/audit.json` (last audit).
- CLI: `python3 skills/paper-writing/scripts/paper_cli.py translate <plan|store|build|audit|status> --lang es [...]` run from the workspace root, one JSON object on stdout, refusals `{"ok": false, "error": CODE, "message": ...}` exit 2, like every paper_cli verb.
- `translate status --lang es` stdout: `{"ok": true, "lang": "es", "blocks": [{"id", "state": "missing"|"current"|"stale", "source_digest", "stored_at"}], "counts": {"total", "current", "stale", "missing"}, "built": bool, "main_tex": "paper/translations/es/main.tex"|null, "pdf": "paper/translations/es/main.pdf"|null, "audit": {"generated_at", "index", "verdict"}|null}`.
- `translate audit --lang es` stdout and `audit.json`: `{"ok": true, "lang": "es", "generated_at", "notice": <the not-an-authorship-detector disclosure>, "document": {"index": 0-100 (higher is better), "style_score": 0-1, "flow_score": 0-1, "redundancy_score": 0-1 (lower is better for the three scores), "verdict": "clear"|"uneven"|"needs_revision"}, "blocks": [{"id", "index", "style_score", "flow_score", "redundancy_score", "verdict", "findings": [{"category", "fragment", "hint", "paragraph", "sentence"}]}], "cross_block_redundancy": [{"phrase"|"sentence", "blocks": [ids]}], "fidelity": [{"id", "ok": bool, "differences": [...]}]}`.

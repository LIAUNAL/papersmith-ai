Objective: `smith ui` refreshes every derived artifact on start, an "Update board" button refreshes them on demand and reports the phase, gates and missing steps; then the flow diagram and docs catch up with releases 0.68-0.78. Branch: feat/dashboard-refresh-and-docs-sync (from main 0.78.0, ccd3a316). Delivery: work-unit commits, merged with --no-ff, then release 0.79.0. Test runner: `.venv/bin/python -m pytest`.

## Specs
- S1. "al dar smith ui asegurste de agtualizar automaticamente todos los artefactos y graficas y fases que lleve el poryecto para proyectarlos e incluirlos en el tablero". Scope: on server start, a background refresh regenerates the local, keyless artifacts (SOTA atlas page, atlas manuscript layer, manuscript graph, novelty graph viewer copy, wiring health) and the phase state; LLM-authored artifacts (proposal sky, journal ranks needing network) are not regenerated. Assumption: an opt-out `--no-refresh` flag keeps the old read-only start.
- S2. "agrega un boton actualizar tablero, en el panle de controles peincipales de arriba del tablero ui, al dar clic el usuario se deben actualziar todos los artefactos sobre el tablero, y revisar que pasos faltab y en que fases o gate estan el proyecto y general mensaje alertando e informando al usario sobre el estado." Scope: the topbar's refresh button becomes "Update board" (POST /api/board/refresh), which regenerates the S1 artifacts, re-reads the status and shows a message with the current phase, its missing steps, the open gates and any artifact that failed.
- S3. "revisa que el flujo archifyy estr actualizado con los cambios de los ultimos release, la descripcion de los agentes, skills,tipos de flujos y fases, documentacion, docs, readme y etc, axtualiza". Scope: docs/diagrams/papersmith-pi-flow.build.mjs and its two rendered copies, docs/diagrams/README.md, README.md, docs/skills.md, docs/cli.md, the harness flow (CLAUDE.md and projections via the template).
- S4. "luego comit, mergea, push y release".
